# Decisions log

What we tried, what we chose, and why. This feeds the notebook's "evidence of development" section and the viva.

| # | Date | Decision | Why | Alternatives considered |
|---|------|----------|-----|-------------------------|
| 1 | 23 Oct | **FastAPI + HTML/JS** for the app, not Streamlit | Vercel runs FastAPI as a serverless function. Streamlit needs a permanent WebSocket connection, which Vercel functions do not support. | Streamlit (not deployable on Vercel); Streamlit Cloud (the brief requires Vercel) |
| 2 | 23 Oct | **No machine-learning libraries in the deployed app.** Product embeddings are computed once in Colab and saved as a file; at search time the app makes one embedding API call per query. | Vercel limits function size; PyTorch and local models are too large and slow to start. | Local embedding model on Vercel (size and cold-start risk) |
| 3 | 23 Oct | **Fixed pipeline, not an agent with tool-calling.** Steps: understand, retrieve, filter, re-rank, decide, answer. | Every search follows the same steps and takes no action in any system (Phase 1, row 4a). A fixed pipeline is cheaper, faster and easier to evaluate step by step. | LLM agent choosing tools (adds cost and unpredictability, no benefit here) |
| 4 | 23 Oct | **Session behaviour is held in the shopper's browser only.** The model receives only the query and a coarse summary (category, product types and price band viewed), never an ID. | Matches the Phase 1 commitment (row 6b). Price variants allow budget and personalisation tests; stock-outs allow constraint tests. | Public e-commerce dataset (licensing and download issues, and not Pakistani household goods) |
| 6 | 23 Oct | **Catalogue text is feature-led; the utility wording lives only in the AI-generated definitions.** | This mirrors real listings and makes the experiment meaningful: if the catalogue already described uses, keyword search would look artificially good and the definitions would show no gain. **Caveat to state honestly:** we wrote the catalogue to avoid use-language, which may make the keyword baseline somewhat weaker than on a real store. | Utility-led descriptions in the catalogue (would undermine the comparison) |
